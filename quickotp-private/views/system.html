Cập nhật trực tiếp

  1. Nhấn Kiểm tra cập nhật, nhập mật khẩu Admin và đánh dấu xác nhận.
  2. Ứng dụng tải ZIP qua HTTPS, kiểm tra SHA-256, manifest, mã PHP và tính tương thích database trước khi thay file.
  3. Website tiếp tục chạy trong lúc tải; tạm bảo trì khi sao lưu dữ liệu và mã nguồn, thay file rồi mở lại. Không đóng tab trong lúc cập nhật.
  4. Cấu hình config.php, thư mục storage và database được giữ nguyên. Bản dữ liệu database.qotp được mã hóa bằng mật khẩu Admin tại thời điểm cập nhật.

Cần extension PHP zip, tokenizer và PHP user có quyền ghi mã nguồn. Nếu hosting thiếu quyền hoặc bản mới đổi schema, dùng cập nhật thủ công theo Release.

Phục hồi khi cập nhật lỗi

Lỗi thay file sẽ tự phục hồi mã nguồn cũ. Nếu tiến trình bị dừng đột ngột, website giữ chế độ bảo trì. Dùng Terminal chạy bản restore.php trong thư mục quickotp-private/storage/updates/<mã cập nhật>/backup/ bằng user website, rồi khởi động lại PHP/LSAPI nếu cần. Hướng dẫn chi tiết trong README.

Cập nhật thủ công

Tạo backup, tải ZIP và kiểm tra checksum. Tạm dừng website, chép mã nguồn/thư viện mới, giữ config.php và storage, khôi phục quyền website rồi làm mới PHP/OPcache. Không chạy lại trình cài trên database đã có dữ liệu.
