Backup & Restore

Sao lưu dữ liệu và khôi phục từ file backup có mật khẩu.

Xác thực tài khoản

Nhập lại mật khẩu đang dùng để tải backup hoặc khôi phục dữ liệu.

Tạo backup

Tải một file .qotp chứa dữ liệu đã được mã hóa bằng mật khẩu riêng.

Khôi phục dữ liệu

Kiểm tra nội dung backup trước khi thay thế dữ liệu hiện tại.

Nội dung bản backup

Bản dự phòng trước khi restore

Hướng dẫn sử dụng

Trang này nhận backup của bản PHP. Backup bản Go dùng định dạng khác.

  1. Sao lưu: nhập mật khẩu Admin hiện tại, đặt mật khẩu backup ít nhất 10 ký tự và bấm “Tạo & tải backup”. Giữ file và mật khẩu ở nơi riêng tư; quên mật khẩu sẽ không mở được file.
  2. Khôi phục: chọn file .qotp, nhập mật khẩu của file và bấm “Kiểm tra backup”. Xem thời gian, phiên bản và số lượng dữ liệu; xác nhận rồi bấm “Khôi phục & đăng xuất”.
  3. Đăng nhập lại: dùng tài khoản và mật khẩu tại thời điểm tạo backup. Các phiên đăng nhập và theo dõi cũ sẽ kết thúc.
  4. Quay lại dữ liệu trước restore: đăng nhập, tải bản dự phòng ở phần trên rồi khôi phục file đó. Mật khẩu của bản dự phòng là mật khẩu file đã dùng ở lần restore tương ứng.
  5. Chuyển máy chủ: cài bản PHP tương thích trên website mới, đăng nhập, sau đó khôi phục file .qotp. App Password IMAP sẽ được chuyển sang khóa mã hóa của máy mới.

Backup gồm tài khoản, cài đặt, danh sách domain, lịch sử địa chỉ email, thư đã lưu, cấu hình IMAP và IP bị chặn. IP đang bị chặn trên máy hiện tại được giữ lại khi khôi phục.

Backup nhanh giới hạn 50.000 bản ghi, 16 MiB dữ liệu và 32 MiB cho file mã hóa. File không chứa source code, chương trình chạy hay thông tin kết nối database của website. Bản dự phòng được lưu trong thư mục backups/ trong quickotp-private/storage; hãy tải ra ngoài máy chủ và theo dõi dung lượng lưu trữ.

Trong lúc xử lý backup/restore, các thao tác khác có thể tạm thời yêu cầu thử lại. Dữ liệu được khôi phục trong một giao dịch; file hỏng hoặc không tương thích sẽ bị từ chối trước khi thay thế dữ liệu.
