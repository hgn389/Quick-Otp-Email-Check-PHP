Quick OTP Mail PHP **v1.0.1** — first stable release.

- Email address generation, message viewing and OTP checks.
- Multiple IMAP accounts and default domain management.
- My Account profile and password management.
- English/Vietnamese interface with light and dark appearance.
- Browser installation and dashboard updates for CyberPanel, OpenLiteSpeed and Apache.

**New installation:** download `Quick-Otp-Email-Check-PHP_v1.0.1-website.zip`, extract into `/home/domain.com/`, then open your website to complete setup. Keep `public_html/` as the document root and `quickotp-private/` beside it. Dependencies are included. See README for requirements and permissions.

**Existing installation:** back up your database, configuration and storage, then use **System status → Check for updates → Update now**. Do not reinstall. Beta_1 users should follow the one-time manual update instructions in README.

The ZIP without `-website` is the dashboard update package. `checksums-php.txt` contains SHA-256 checksums for both downloads. Previous beta releases remain available.
