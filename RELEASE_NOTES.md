Quick OTP Mail PHP **v1.0.0 beta_1**.

For a fresh CyberPanel website, download **Quick-Otp-Email-Check-PHP_v1.0.0-beta_1-website.zip**. Create the website, SSL and database; extract the ZIP directly into `public_html`, keeping hidden `.htaccess` files; then open the website and enter the database details and your chosen Admin password.

The website ZIP includes dependencies. No Composer, terminal commands or manual installation token are required. This release also fixes the browser installer’s invalid Origin error.

Requirements: PHP 8.3+, MySQL 8.0+ or MariaDB 10.6+, HTTPS and enabled rewrite/Auto Load `.htaccess`. PHP extensions and detailed instructions are listed in README.md.

Assets:
- `Quick-Otp-Email-Check-PHP_v1.0.0-beta_1-website.zip`: ready-to-upload fresh installation.
- `Quick-Otp-Email-Check-PHP_v1.0.0-beta_1.zip`: canonical package for the built-in updater and split-directory layout.
- `checksums-php.txt`: SHA-256 checksums for both ZIPs.

GitHub's automatic Source code archives are developer checkouts without bundled dependencies. Use the website ZIP to install through your browser.
